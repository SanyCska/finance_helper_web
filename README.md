# Finance Helper — Mini App

Telegram Mini App личного финансового помощника. Бэкенд лежит рядом:
`../finance_helper_back`, там же docker-compose и инструкция по боту.

## Запуск

```bash
npm install
npm run dev
```

Аппа поднимется на `http://localhost:3010`. Адрес API берётся из `.env.local`:

```
NEXT_PUBLIC_API_BASE_URL=http://localhost:8010
```

Вне Telegram приложение работает как обычная веб-страница — удобно для отладки.
Чтобы бэкенд пускал такие запросы, включите на нём `DEV_BYPASS_AUTH=true`
(флаг игнорируется при `ENV=production`).

Внутри Telegram запросы подписываются `initData`, который клиент кладёт
в заголовок `Authorization: tma <initData>`.

## Экраны

| маршрут | что показывает |
|---|---|
| `/` | сальдо месяца, донат трат, топ категорий, последние операции |
| `/transactions` | операции по дням с фильтрами по категориям и поиском |
| `/add` | добавление траты вручную |
| `/categories` | разбивка месяца по категориям |
| `/category/[name]` | динамика одной категории по месяцам |
| `/compare` | сравнение двух месяцев |
| `/plan` | строки плана, доход месяца, ожидаемое сальдо |
| `/plan/vs-fact` | план против факта |

Выбранный месяц живёт в строке запроса (`?month=2026-07`), поэтому переживает
переходы между экранами и возврат по кнопке «назад».

## Устройство

```
app/          маршруты Next.js (App Router) и глобальные стили с токенами дизайна
components/   экраны и переиспользуемые блоки, включая графики на голом SVG/CSS
lib/          формат сумм и дат, клиент API, обёртка Telegram, цвета категорий
tests/        Vitest: форматтеры, геометрия доната, цвета
```

Графики нарисованы вручную: донат — через `conic-gradient`, столбцы и полосы — через
flex. Библиотека чартов потребовала бы больше кода на переопределение стиля
(нулевые радиусы, двухпиксельные линейки, `tabular-nums`), чем сама отрисовка.

### Шрифты

Мокапы сделаны на Archivo, но у неё нет кириллицы. Archivo оставлен для цифр и латиницы
— на них держится вся типографика сумм, — а кириллица падает на Inter: тот же
нейтральный гротеск с начертанием 800. Оба шрифта подключаются через `next/font`,
внешних CDN в рантайме нет.
